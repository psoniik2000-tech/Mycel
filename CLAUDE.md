# Mycel — правила для Claude

Проект: P2P-мессенджер на Rust без серверов. Описание — `docs/DESIGN.md` (читать только нужный раздел, не весь файл).

## Режим работы
- В начале сессии включай `/ponytail full`: минимальный полный diff, без лишних абстракций и «на будущее».
- Экономия токенов: короткие ответы, без пересказа сделанного, читать файлы частями (offset/limit, grep), не перечитывать то, что уже в контексте.
- Широкий поиск и рутину (сборка, прогон тестов, чтение логов) отдавай субагентам на дешёвой модели (`model: haiku`/`sonnet`), себе забирай только вывод.
- Каждая фаза из `docs/DESIGN.md` §16 — отдельная новая сессия с коротким брифом: цель, файлы, критерий готовности. Не тянуть одну длинную сессию.
- Отвечать пользователю по-русски.

## Код
- Cargo workspace, крейты в `crates/`, приложение в `apps/mycel-app` (структура — §13).
- Перед коммитом: `cargo fmt`, `cargo clippy`, `cargo test` для затронутых крейтов.
- Мусор сборки держит под 15 ГБ (debug-кэш с OpenSSL переживает очистку) задача Windows `MycelClean` (`scripts\clean.ps1`, каждые 15 мин; поставить заново: `scripts\install-clean-task.ps1`). Сессия в worktree после push в main удаляет свой worktree (`git worktree remove --force`).
