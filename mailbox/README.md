# Почтовый ящик Mycel (Cloudflare Worker, бесплатно)

Хранит зашифрованные сообщения для тех, кто не в сети, до 30 дней. Получатель забирает их, когда откроет Mycel, даже если отправитель уже офлайн. Ящик видит только шифр, прочитать переписку не может.

Бесплатного тарифа Cloudflare хватает с запасом: 100 000 запросов в день. Одно запущенное приложение делает около 1 500 запросов в сутки, плюс до 22 на каждое сообщение, пока на него нет квитанции.

## Установка (через сайт, без командной строки)

1. Зарегистрироваться на https://dash.cloudflare.com (бесплатный план).
2. **База:** слева «Storage & Databases» → «D1 SQL Database» → «Create» → имя `mycel-box` → «Create». Таблицу создавать не нужно, Worker сделает это сам.
3. **Worker:** слева «Compute (Workers)» → «Workers & Pages» → «Create» → «Start with Hello World» → имя `mycel-box` → «Deploy».
4. «Edit code» → удалить всё → вставить содержимое файла [`worker.js`](worker.js) → «Deploy».
5. **Привязать базу:** на странице Worker'а «Settings» → «Bindings» → «Add» → «D1 database» → Variable name: `DB`, база: `mycel-box` → «Deploy».
6. Открыть адрес Worker'а (вида `https://mycel-box.ИМЯ.workers.dev`) в браузере. Должно появиться «Mycel mailbox works».
7. В Mycel на каждом устройстве: «Настройки» → «Связь» → «Почтовый ящик» → вставить адрес → «Сохранить». Или один раз вписать его в `DEFAULT_MAILBOX` в `apps/mycel-app/src/App.tsx` и пересобрать: тогда он будет у всех по умолчанию.

## Пуши на телефоны (Firebase, по желанию)

Ящик будит телефоны через Firebase Cloud Messaging, даже когда Mycel закрыт. В пуше нет содержимого, только сигнал «есть новое».

1. На console.firebase.google.com → Project settings → Service accounts → «Generate new private key». Скачается `.json`, это секрет.
2. В Cloudflare: Worker `mycel-box` → «Settings» → «Variables and Secrets» → «Add» → Type: **Secret**, Name: `FCM_KEY`, Value: всё содержимое этого `.json` (открыть в Блокноте, Ctrl+A, Ctrl+C) → «Deploy».

Проект Firebase зашит в `Push.kt` (Android). Для своего проекта поменяйте там значения из `google-services.json`.

## Как это работает

- Каждое новое сообщение (и квитанция о доставке) дополнительно отправляется в ящик: `POST /box/<тема>/<id>`.
- Приложение при запуске и раз в минуту забирает новое: `GET /box/<тема>?after=<номер>`. Пока на своё сообщение нет квитанции — раз в 5 секунд, но не дольше 2 минут после отправки.
- Тема — хеш от id пространства, который знают только участники. Дубликаты отбрасываются по id.
- Файлы и фото в ящик не попадают, только сами сообщения. Содержимое файла скачается, когда в сети будет автор или якорь.
