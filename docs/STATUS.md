## Где что лежит

- `crates/mycel-core` — узел (`Node`): сеть, MLS, синхронизация, медиа, звонки. Главное API для UI.
- `crates/mycel-anchor` — CLI и режим якоря (`serve`).
- `apps/mycel-app/src-tauri/src/main.rs` — команды Tauri (мост UI ↔ `Node`).
- `apps/mycel-app/src/` — UI: `App.tsx` (экраны, чат), `media.tsx`, `call.ts`, `capture.ts`, `styles.css`.

## Правила

- Ответы пользователю — по-русски, пользователь не программист.
- `/ponytail full`, экономия токенов (см. `CLAUDE.md`).
- Перед коммитом: `cargo fmt`, `cargo clippy`, `cargo test` для затронутых крейтов; CI должен быть зелёным.
- Параллельные задачи идут в своих git-worktree на своих ветках; в конце — `git pull --rebase origin main`, тесты, push в main.
- Пользователь дал все разрешения: не спрашивать подтверждения на установку инструментов, сборку, коммит и push.

## Дальше (очередь)

1. **A. Сообщения как в Telegram.** Пузыри с хвостиком, время и галочки внутри пузыря, группировка подряд идущих сообщений, разделители дат, плавная прокрутка вниз и кнопка «вниз», Enter — отправить, Shift+Enter — новая строка, отправка не теряется и не дублируется. Контекстное меню (ПКМ / долгое нажатие): ответить (цитата), копировать, редактировать, удалить у себя / у всех, переслать, закрепить; выделение нескольких сообщений и массовое удаление/копирование. В протоколе — события `Edit`, `Delete`, `Reply` (ссылка на id события).
2. **B. Android (фаза 4).** Tauri 2 Android: APK в CI, фоновая служба, уведомления, камера/микрофон, QR-сканер для инвайтов, вёрстка под телефон.
3. **Демонстрация экрана.** Захват экрана/окна (ПК), передача видеопотоком звонка, выбор окна, режим «только звук системы».
4. **Фаза 5: устойчивость** — Tor (arti), TLS-443, LAN/mDNS, офлайн-пакеты, экран «Сеть».
5. **Резервная копия и мультиустройства** — 24 слова, добавление устройства по QR (DESIGN §4.4).

## Известные долги

- Якорь не проверен на реальном роутере (проброс порта).
- Рация (push-to-talk) работает, только когда окно Mycel активно.
- Видео в звонке проверено только тестами (камера на ПК разработки не включалась).
- `grep -rn "shortcut:"` — список сознательных упрощений (`/ponytail-debt`).
