### Android: как поставить на телефон

1. Скачать APK: GitHub → Actions → последний зелёный CI → artifact `mycel-android-apk` (или собрать: `cd apps\mycel-app; npx tauri android build --apk --target aarch64`, нужны JDK 17, Android SDK/NDK — см. ниже).
2. Перекинуть `.apk` на телефон, открыть, разрешить «установку из неизвестных источников».
3. При первом запуске разрешить уведомления; камеру/микрофон Android спросит при первом звонке или скане QR.
4. Вступить: «Сканировать QR» и навести на QR из ПК-версии (Люди → Пригласить).
5. Чтобы сообщения приходили в фоне, не закрывайте уведомление «Mycel на связи» и отключите для Mycel экономию батареи.

Сборка на ПК разработчика: JDK 17 в `C:\Android\jdk17`, SDK в `C:\Android\Sdk` (NDK 28.2), переменные `JAVA_HOME`, `ANDROID_HOME`, `NDK_HOME`; `rustup target add aarch64-linux-android armv7-linux-androideabi x86_64-linux-android`. Эмулятор: AVD `mycel`, `emulator -avd mycel`. На этом ПК `npx tauri android build` сам не доходит до конца (нет прав на симлинки, perl из Git урезан), поэтому собирать так: `bash C:\Android\build-apk.sh release aarch64` (или `debug x86_64` для эмулятора). Release-ключ в CI — секреты `ANDROID_KEY_BASE64`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`; без них APK подписан debug-ключом.

## Где что лежит

- `crates/mycel-core` — узел (`Node`): сеть, MLS, синхронизация, медиа, звонки. Главное API для UI.
- `crates/mycel-anchor` — CLI и режим якоря (`serve`).
- `apps/mycel-app/src-tauri/src/lib.rs` — команды Tauri (мост UI ↔ `Node`); `main.rs` только вызывает `run()` (раньше там лежала старая копия всех команд — ПК-сборка шла из неё).
- `apps/mycel-app/src-tauri/gen/android` — Android-проект (фоновая служба `NodeService.kt`, разрешения в `AndroidManifest.xml`).
- `apps/mycel-app/src/` — UI: `App.tsx` (экраны, чат), `media.tsx`, `call.ts`, `capture.ts`, `styles.css`.

## Правила

- Ответы пользователю — по-русски, пользователь не программист.
- `/ponytail full`, экономия токенов (см. `CLAUDE.md`).
- Перед коммитом: `cargo fmt`, `cargo clippy`, `cargo test` для затронутых крейтов; CI должен быть зелёным.
- Параллельные задачи идут в своих git-worktree на своих ветках; в конце — `git pull --rebase origin main`, тесты, push в main.
- Пользователь дал все разрешения: не спрашивать подтверждения на установку инструментов, сборку, коммит и push.

## Известные долги

- Пересылка: нет пометки «Переслано от».
- Личный чат открывается только с тем, у кого новая версия (есть профиль с ключом); у старых клиентов — ошибка «нет профиля».
- Чат в ядре: `Chat = Option<device>` (None — общий). Если двое одновременно открыли чат друг с другом, будет две MLS-группы; сообщения обеих показываются в одном чате, отправка — в группу с меньшим id.
- В список «Звонков» и статусы ✓✓ личного чата считаются по участникам этого чата.
- «Удалить у всех» стирает текст и файл на устройствах, но зашифрованный MLS-конверт лежит у якоря до конца срока хранения (прочитать его уже нельзя).
- Якорь не проверен на реальном роутере (проброс порта).
- Рация (push-to-talk) работает, только когда окно Mycel активно.
- Android: QR-сканер, звонки (видео/звук) и уведомление о входящем звонке проверены в эмуляторе (виртуальная камера) с ПК, 10 звонков подряд в обе стороны; на живом телефоне — нет. «Открыть»/«Сохранить» медиа на Android не сделаны.
- Если сообщение не ушло и после всех повторов, оно догоняется только при следующем запуске (sync только на старте).
- Без своего якоря связь зависит от публичных relay/DNS n0; при их недоступности (VPN, блокировки EU-серверов) узлы не находят друг друга.
- Видео в звонке проверено только тестами (камера на ПК разработки не включалась).
- `grep -rn "shortcut:"` — список сознательных упрощений (`/ponytail-debt`).
